# First Beta Customer Setup

Use this runbook for the first controlled beta account. Keep the setup narrow: one assistant, one website, one public Front Desk, and a small set of approved answers.

1. Create or choose the customer's assistant in the dashboard.
2. Add the customer's business website.
3. Import website knowledge and confirm the import completes.
4. Fill the Business Profile with the business name, contact details, service area, hours, and any important limits.
5. Add 3-5 approved answers for the questions the customer already knows visitors ask most often.
6. Enable the public Front Desk page and copy the public link.
7. Install either the WordPress plugin or the smart embed on the customer's site.
8. Test the public page with customer-style questions about services, pricing, contact, booking, and policies.
9. Test feedback by marking at least one answer helpful or not helpful, then confirm it appears for review.
10. Monitor the first conversations daily and turn real gaps into approved answers or source content updates.
