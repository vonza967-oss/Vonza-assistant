# Paid Pilot Plan

## First ICP

Start with service businesses that receive repeated website inquiries and benefit from faster first response: home services, clinics/wellness studios, local repair/install businesses, and appointment-led local services.

Best first wedge: owner-operated home services or wellness/service studios with an existing website, clear pricing or booking intent, and missed calls/forms from customers asking the same questions.

## Pilot Target

Recruit 5-10 paid pilot users. Keep the cohort small enough to onboard manually and inspect every account weekly.

## Pilot Pricing

Suggested paid-pilot pricing:

- Starter pilot: $20/month for low-traffic sites.
- Growth pilot: $50/month for most pilot accounts.
- Pro pilot: $100/month for busier sites or accounts needing more monthly AI capacity.

Use Stripe test mode for staging verification. Use live Stripe prices only after staging checkout and webhook verification pass.

## Onboarding Checklist

- Confirm business website URL and primary service area.
- Confirm target customer actions: call, email, booking, quote request, or visit.
- Import website content and verify the summary.
- Configure assistant name, greeting, tone, and key contact details.
- Add business-specific weak-answer fixes for pricing, availability, service area, and emergency/urgent cases.
- Install agent or verify preview with the owner.
- Send 5-10 representative test questions before launch.
- Confirm lead capture language and owner follow-up path.
- Review first real conversations within 24-48 hours.

## Success Metrics

Track weekly per account:

- Conversations handled
- Leads captured
- Bookings/quotes started
- Weak-answer fixes added and resolved
- AI cost per account
- Setup time from signup to usable agent
- Churn/retention notes
- Testimonial/proof points

## 30/60/90 Day Timeline

Days 1-30:

- Onboard 5 pilot users manually.
- Verify agent install or preview for every account.
- Review weak answers twice weekly.
- Establish baseline conversation, lead, and AI cost metrics.

Days 31-60:

- Expand to 10 pilot users if support load is manageable.
- Identify the highest-performing ICP segment.
- Tighten onboarding around recurring setup issues.
- Collect first testimonial or before/after support response proof.

Days 61-90:

- Decide whether to keep, adjust, or narrow the ICP.
- Compare retention and usage by segment.
- Confirm gross margin against AI cost per account.
- Convert successful pilots to normal monthly pricing or a defined annual offer.
- Document the top objections, required fixes, and proof points for the next cohort.

## Pilot Blockers

- Staging checkout must pass with plan-specific Stripe test prices before collecting paid pilots.
- Clean database validation should pass before staging is considered deploy-ready.
- The first cohort needs manual onboarding capacity; do not broaden acquisition until setup time and weak-answer handling are predictable.
